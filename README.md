# Chat Barbara

Bem-vindo ao repositório do **Chat-Barbara**! Este é um projeto de Chatbot desenvolvido em Python, com uma interface gráfica moderna e integração direta com Inteligência Artificial e buscas na internet.

## Funcionalidades

- **Interface Gráfica Moderna:** Desenvolvida com a biblioteca customtkinter.
- **Personalidade Única:** O bot foi configurado para agir como a Alegria (do filme Divertida Mente).
- **Pesquisa em Tempo Real (Web Search):** Integrado com a API do DuckDuckGo para buscar fatos recentes.
- **Poderosa API de IA:** Processamento via API da NVIDIA com o modelo z-ai/glm-5.2.

## Arquivos

- main.py: Interface e Chatbot principal.
- chatIa.py: Script de teste com stepfun-ai.
